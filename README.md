# 🐍 Python Mundo 2

Repositório desenvolvido durante o **Mundo 2 do curso de Python**, dando continuidade aos estudos iniciados no Mundo 1.

Nesta etapa, o objetivo é aprofundar os conhecimentos em Python, desenvolver ainda mais a lógica de programação e começar a construir programas com estruturas mais completas e interativas.

---

## 📚 Sobre o curso

O **Mundo 2** representa uma nova etapa da minha jornada de aprendizado em Python.

Depois de construir a base da linguagem no Mundo 1, começo agora a trabalhar com conceitos que permitem criar programas mais dinâmicos, capazes de tomar decisões, repetir processos e lidar com diferentes situações.

O conteúdo será aplicado tanto nos exercícios e desafios do curso quanto no desenvolvimento gradual do **HotelHub**.

---

## 🎯 Objetivos

- Aprofundar os fundamentos de Python.
- Desenvolver ainda mais a lógica de programação.
- Aprender a trabalhar com estruturas de controle.
- Criar programas mais interativos e dinâmicos.
- Praticar a resolução de problemas.
- Melhorar a organização e legibilidade dos códigos.
- Continuar utilizando Git e GitHub para registrar minha evolução.
- Aplicar os novos conhecimentos no desenvolvimento do HotelHub.
- Construir uma base cada vez mais sólida para projetos futuros.

Os desafios serão utilizados para colocar em prática os conceitos apresentados nas aulas e desenvolver a capacidade de resolver problemas utilizando Python.

A pasta `desafios/hotelhub/` reunirá as missões relacionadas ao HotelHub.

## 🏨 HotelHub

O **HotelHub** é um projeto paralelo desenvolvido durante meus estudos de Python.

A proposta é transformar os conhecimentos adquiridos no curso em funcionalidades relacionadas à gestão de pousadas e hotéis.

No Mundo 2, o objetivo será começar a utilizar os novos conhecimentos para tornar o projeto mais interativo e próximo de um sistema real.

O projeto continuará evoluindo gradualmente ao longo dos próximos módulos.
